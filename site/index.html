A terminal app for coding agents

Five agents. One terminal. No collisions.

Adroit runs Claude Code, Codex, Gemini or Aider side by side. Each session gets its own git worktree and tmux session, and every row shows its branch, CI result and pull request.

Scenes
Theme

Every agent gets its own checkout.

Two agents in one working tree overwrite each other. Adroit gives each one a separate branch and directory, and keeps it running when you look away.

git worktree
A branch and a directory per session, under ~/.adroit/worktrees. Your main checkout stays untouched.
tmux
A terminal per session that keeps running when you close the window. Attach with ↵, detach with ctrl-q.
the list
One screen over all of them: what each agent is doing, its diff, its CI and its pull request.

CI and review state on every row

Each row reads its pull request from gh: checks, mergeability, review state and comments. g opens it in the browser.

✓ passed✗ failed◌ running◆ merged★ approved

Drift you can see

Adroit fetches once a minute and marks a worktree that has fallen behind its branch. u fast-forwards it, or resets it after a force-push.

↓3 behind⇅3/1 diverged↑2 unpushed

Review before you push

Each session has a Preview, Diff and Terminal tab. c commits and pauses a session to free its worktree. r resumes it.

Run the stack in one worktree

d starts your dev servers in the selected session. Readiness lamps go green per port, and the stack follows you when you switch sessions.

Any agent, per session

Claude Code by default. Define profiles for Codex, Gemini or Aider and pick one each time you press n.

Eight themes

t opens a picker that recolors the whole interface as you move through it. Try them on the terminal above.

Set up a new machine in a minute.

The installer downloads the release for your platform, checks its checksum, puts adroit on your PATH and then runs adroit doctor.

# latest release into ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/AlexanderWeismannn/adroit/main/install.sh | bash

# also install tmux and gh, and link `cs`
curl -fsSL …/install.sh | bash -s -- --install-deps --with-cs
# needs Go 1.23 or newer
go install github.com/AlexanderWeismannn/adroit@latest
git clone https://github.com/AlexanderWeismannn/adroit
cd adroit
go build -o ~/.local/bin/adroit .
