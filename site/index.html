adroit

Run Claude Code, Codex, Gemini or Aider side by side. Each session gets its own git worktree and tmux session, so agents never edit the same checkout.

Linux, macOS and WSL. Needs git and tmux.

──┬──┬── 
$ curl -fsSL https://raw.githubusercontent.com/AlexanderWeismannn/adroit/main/install.sh | bash
$ go install github.com/AlexanderWeismannn/adroit@latest
$ git clone https://github.com/AlexanderWeismannn/adroit && cd adroit
$ go build -o ~/.local/bin/adroit .

Then cd into a git repository and run adroit. adroit doctor lists anything missing and how to install it.

Recorded from the real app (demo/record.py), with a scripted stand-in agent so the run is repeatable.

─Instances · 5─
1.parallel sessions⠹A branch, a worktree and a tmux session per task. Your main checkout stays untouched.
2.review before you push+6 -4Preview, Diff and Terminal tabs per session. Commit and push, or check the branch out.
3.status at a glance✓ doneEach row shows whether its agent is working, waiting for you or finished, plus CI and PR state from gh.
4.any agent●Claude Code by default. Add profiles for Codex, Gemini or Aider and pick one per session.
5.dev stack and themestd runs your servers in the selected worktree. t picks one of eight themes, previewed live.
